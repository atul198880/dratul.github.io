# Dr. Atul Kumar — GitHub Pages Website

## How to publish

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, `publications.html`, and this README.
3. Optional: upload your CV as `cv.pdf`.
4. Go to **Settings → Pages**.
5. Select **Deploy from a branch → main → / (root)**.
6. Save and open `https://YOURUSERNAME.github.io/`.

## Important
Replace `your-email@example.com` with your actual email and update the publication entries with exact bibliographic information.
